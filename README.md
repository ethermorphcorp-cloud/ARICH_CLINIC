## Feature

### ส่วนที่ ARICH ต่างจาก VALIN (สรุป)
- **Stock ยา A / B**: ยาแต่ละรายการอยู่ใน Stock A หรือ B (ยาชื่อเดียวกันใน 2 stock = 2 รายการ ไม่ย้ายข้าม stock) หน้าจัดการสินค้ามีแท็บ "รายการยา Stock A" / "รายการยา Stock B" และทุกช่องเลือกยาแสดงเป็น `ชื่อยา [Stock X]`
- **ราคาตาม Sale group / Sale agent** (ชีต `SaleGroups`, `Sales.GroupID`, `PriceOverrides`): เซลล์สังกัดได้ 1 กลุ่ม ตั้งกลุ่มและย้ายเซลล์ได้ที่ ตั้งค่า > แพทย์/เซลล์ (ย้ายแล้วบันทึกลง AuditLog; ลบ/ปิดกลุ่มที่ยังมีสมาชิกไม่ได้) · ตารางราคา 1 แถว = 1 ยา × 1 กลุ่มหรือ 1 เซลล์ (ขั้น x1/x3/x5/x10/x20/x50 ช่องว่าง = ไม่มีราคาขั้นนั้น) · ลำดับ **Sale Agent → Sale group → Standard** ใช้ **ทั้งตาราง** ของระดับที่เจอ ไม่ผสมรายขั้นข้ามระดับ · ขั้นที่ใช้ = ขั้นใหญ่สุดที่ไม่เกินจำนวน และข้ามช่องว่าง · หน้ายาเลือกดูราคาของกลุ่ม/เซลล์ได้ มีคอลัมน์ "ที่มาของราคา" (ตัวเลขจาง = ใช้ตารางของระดับล่าง, แดง = ต่ำกว่าทุน) และฟอร์มแก้ไขเตือนราคาที่ต่ำกว่าทุน · บรรทัดซื้อยาเพิ่มเก็บ `priceSource` (agent/group/standard/manual), `priceRefId`, `tier`, `unitCost` ไว้ในบิล ราคาที่แก้ภายหลังจึงไม่กระทบบิลเก่า
- **OPD** (เดิมชื่อ "บันทึกการรักษา"): ส่วนยา = ถือยาเข้า, ยาฝาก, ยาเบิก (จากจัดยา-เบิกยา, มีหมายเหตุต่อบรรทัด), **ซื้อยาเพิ่ม** (เลือก Stock A/B ต่อบรรทัดแล้วเลือกยาใน stock นั้น, ตัดสต๊อก, จำนวนซื้อ/ใช้/ฝาก, ราคาต่อหน่วยดึงตามเซลล์แก้ได้, **คิดเงินในยอดชำระ** ไม่คิดค่าคอม, รองรับยาอื่นๆ ที่ไม่มีในสต๊อก), **พัสดุ** (เลือกยาจากสต๊อกและตัดสต๊อก); หัตถการมีช่องรายละเอียดต่อบรรทัด และ "อื่นๆ (ระบุเอง)"; Canula มีหมายเหตุ; แนบ **รูป Before / After** อย่างละไม่เกิน 8 รูป (แทนรูป OPD); กด "บันทึกการรักษา → รอชำระเงิน" แล้วแสดงพรีวิว **ใบ OPD ขนาด A5** ให้พิมพ์ทันที (`OpdSheet.html`; พิมพ์ซ้ำได้จากแผงรายละเอียดของรายการ)
- **ยอดชำระ** = หัตถการ + โปร + Canula + อื่นๆ + ซื้อยาเพิ่ม · **ค่าคอมเซลล์** = หัตถการ × % · **ค่าหมอ** = หัตถการ × %แพทย์ + โปร × %โปร (+ เติมยอดขั้นต่ำรายวัน)
- **ชื่อ Stock A / B**: ตั้งได้ที่ ตั้งค่าคลีนิค > ข้อมูลบริษัท (ClinicSettings `stockNameA` / `stockNameB`, ไม่เกิน 30 ตัวอักษร ห้ามซ้ำ) แล้วเปลี่ยนทุกหน้า: แท็บจัดการสินค้า/บริการ, แท็บรายการยาฝาก (แยก Stock A/B), ช่องเลือกยา/dropdown ใน OPD, ใบ OPD
- **ตั้งค่า > แพทย์/เซลล์**: Sale group อยู่ซ้าย (ทั้งหมด / แต่ละกลุ่ม / ไม่มีกลุ่ม) เลือกแล้วเห็นเซลล์ทางขวาเป็นการ์ดเรียงลงมา แสดงชื่อเซลล์, Sale group (dropdown เปลี่ยนกลุ่มได้ทันที), สถานะ, อัตราค่าคอม, ปุ่มแก้ไข/ลบ
- **ใบสั่งซื้อ (ค่าใช้จ่าย & จัดซื้อ)** มี 2 ประเภท (`Orders.OrderType`): **ซื้อยาจากเซลล์** (ระบุเซลล์ เลือกได้เฉพาะยาจาก stock เพิ่มเข้า stock แต่ **ไม่นับเป็นค่าใช้จ่ายคลินิก** เพราะต้นทุนไปอยู่ในค่าต้นทุนยา) และ **ซื้ออื่นๆ / เวชภัณฑ์ทั่วไป** (เพิ่มเข้า stock และนับเป็นค่าใช้จ่ายคลินิก) · ใบสั่งซื้อเดิมที่ไม่มีประเภทนับเป็นซื้ออื่นๆ · กรองรายการตามประเภทได้
- **จัดการสินค้า/บริการ**: ปุ่มเพิ่ม / อัพเดตสต๊อก / อัปโหลด CSV / Template CSV รวมเป็น dropdown "จัดการ…" ปุ่มเดียว
- **รายงานรายเซลล์**: ราคาทุน/หน่วย, จำนวนเงิน (ทุน), **ราคาขายเซลล์**/หน่วย + จำนวนเงินรวม, **ราคาลูกค้าจ่าย**/หน่วย + จำนวนเงินรวม (เฉพาะซื้อยาเพิ่มหน้าคลินิก), **ส่วนต่างสุทธิ** = ราคาขายเซลล์ − ราคาทุน, **ส่วนต่างคืนเซลล์** (สีแดง) = ราคาลูกค้าจ่าย − ราคาขายเซลล์ — เช่น ทุน 2,500 / ขาย 3,500 / ลูกค้าจ่าย 4,000 → สุทธิ 1,000, คืนเซลล์ 500; ราคาขายเซลล์ของซื้อยาเพิ่มเก็บไว้ในบรรทัดยาตอนบันทึก (salePrice, รายการเก่าใช้ราคาตามตารางราคาปัจจุบัน); Dashboard ยังนับรายได้ยาตามเงินที่คลินิกเก็บจริง
- **Dashboard**: การ์ด 5×2 — แถวบน: รายได้รวม (= รายได้คลินิก + รายได้ยา), รายได้คลินิก (หัตถการ + โปร + Canula + อื่นๆ), รายได้ยา (ราคาขายยาเบิก + ซื้อยาเพิ่ม), กำไรสุทธิ (+%), จำนวนคนไข้ · แถวล่าง: ค่าใช้จ่ายรวม (= คลินิก + ต้นทุนยา + ค่าคอมหมอ + ค่าคอมเซลล์), ค่าใช้จ่ายคลินิก (ค่าใช้จ่าย + ใบสั่งซื้อประเภทซื้ออื่นๆ), ค่าต้นทุนยา, ค่าคอมหมอ, ค่าคอมเซลล์ · กำไรสุทธิ = รายได้รวม − ค่าใช้จ่ายรวม · กราฟรายเดือน/รายหมวดใช้นิยามเดียวกัน, รายได้ vs ค่าใช้จ่ายคลินิก (รายวัน), รายได้ยา vs ต้นทุนยา vs กำไร (รายวัน), ค่าคอมรายเซลล์, ค่าหมอรายแพทย์


### ระบบผู้ใช้และสิทธิ์
- Login ด้วย username/password (hash + salt) และ session token เก็บใน CacheService อายุ 6 ชม.
- มี 2 ระดับคือ **admin** และ **staff** โดย Dashboard, รายงาน, ค่าใช้จ่าย & จัดซื้อ และตั้งค่าคลินิก ใช้ได้เฉพาะ admin
- ผู้ใช้เปลี่ยนรหัสผ่านเองได้ และ admin รีเซ็ตรหัสพนักงานได้
- บันทึกทุกการเปลี่ยนแปลงลง AuditLog

### Flow การทำงาน
จัดยา-เบิกยา (สถานะ **จัดยาแล้ว** — มักจัดล่วงหน้าก่อนวันนัด; ยังไม่รู้ชื่อคนไข้ก็พิมพ์ชื่อไว้ได้ จะแสดง "รออัพเดท") → Front เปลี่ยนเป็น **รอดำเนินการ** (ต้องใส่ข้อมูลคนไข้ — เลือกจากประวัติหรือสร้างใหม่ — แล้ว Front สร้าง **ใบ OPD**) → ลูกค้ามา Front กด **รอพบแพทย์** (ได้เลขคิวของวัน) → Front เรียกเข้าพบ โดยเลือกแพทย์ → **พบแพทย์** (ระบบแสดงตัวอย่างใบ OPD พร้อมปุ่มพิมพ์) → แพทย์เพิ่มบันทึกการรักษา (บันทึกแล้วเป็น **รอชำระเงิน** ทันที) → Front รับชำระเงิน (**เสร็จสิ้น**)

**ใบ OPD** = การบันทึกฟอร์มบันทึกการรักษาครั้งแรก (ฟอร์มเดียวกัน) — ต้องมีก่อนพบแพทย์; บันทึกที่สร้างเองโดยไม่ผ่านการจัดยาเริ่มที่ รอดำเนินการ; เปลี่ยนสถานะจัดยาแล้ว → รอดำเนินการ ทำได้ที่หน้า จัดยา-เบิกยา (เมนู "จัดการ") และเปลี่ยนเป็นขั้นอื่นข้ามไม่ได้; **สร้างใบ OPD** ได้จากเมนู "จัดการ" ของรายการจัดยาแล้ว (หน้า จัดยา-เบิกยา — ถ้ายังไม่มีข้อมูลคนไข้ เมนูมี เพิ่มข้อมูลคนไข้ / สร้างใบ OPD ซึ่งให้ใส่ข้อมูลคนไข้ก่อน) หรือจากการ์ด รอดำเนินการ — บันทึกใบ OPD แล้วสถานะเปลี่ยนเป็น **รอพบแพทย์** (ได้เลขคิว) ทันที; การ์ด รอชำระเงิน กดย้อนกลับไป พบแพทย์ได้ — บันทึกการรักษาที่สร้างแล้ว (เคยถึงรอชำระเงิน) ทุกการแก้ไขต้องระบุ **หมายเหตุการแก้ไข** (เก็บผู้แก้/เวลา แสดงในฟอร์มและแผงรายละเอียด); รายการเสร็จสิ้นแก้ไขได้เฉพาะ admin; ฟอร์มแสดงเลขที่รายการรักษา; เมนู "จัดการ" ของรายการที่ยังรออัพเดทมี "ใส่ข้อมูลคนไข้"

เลขคิวเริ่มนับเมื่อเปลี่ยนเป็นรอพบแพทย์ รันต่อเนื่องในแต่ละวัน (เริ่ม 1 ใหม่ทุกวัน) และคนไข้ใช้เลขเดิมตลอดจนเสร็จสิ้น; ย้อนสถานะได้ตราบที่ยังไม่ชำระ; เสร็จสิ้น = ชำระเงินแล้ว; **ยังไม่มีบันทึกการรักษาในขั้นจัดยาแล้ว/รอพบแพทย์** — ฟอร์มบันทึกการรักษาเปิดได้ตั้งแต่ขั้นพบแพทย์; บันทึกการรักษาที่สร้างเองโดยไม่ผ่านการจัดยาเริ่มที่พบแพทย์; ตอนกด รอพบแพทย์ วันที่ของบันทึกที่จัดยาไว้ล่วงหน้าจะเปลี่ยนเป็นวันที่ลูกค้ามา

### เมนูหลัก
1. **Dashboard** (admin): **รายได้** = ที่เก็บจากลูกค้า (หัตถการ, โปร, Canula, อื่นๆ — เฉพาะบันทึกที่ชำระแล้ว) + ที่เก็บจากเซลล์ (รายงานรายเซลล์ ณ ราคาทุน); **รายจ่าย** = ค่าใช้จ่าย + จัดซื้อ + ส่วนแบ่งแพทย์ + ส่วนแบ่งเซลล์; กำไร = รายได้ − รายจ่าย. การ์ด: รายได้รวม, รายจ่ายรวม, กำไร (พร้อม %กำไร), จำนวนคนไข้; กราฟ: รายเดือน (แสดงเฉพาะเดือนที่มีข้อมูล) → รายได้รายหมวดหมู่ (รวมกันเท่ากับรายได้รวม) + รายจ่ายรายหมวดหมู่ (รวมกันเท่ากับรายจ่ายรวม) → สัดส่วนส่วนแบ่งแพทย์ / ส่วนแบ่งเซลล์ / รายได้รายโปรโมชัน เลือกช่วงวันที่ได้ และ cache ผลไว้ (ล้างอัตโนมัติด้วย version bump ทุกครั้งที่มีการบันทึก)
2. **ข้อมูลคนไข้**: ประวัติ (เลข HN **รันอัตโนมัติ**เมื่อสร้างประวัติใหม่ — แก้ภายหลังได้แต่ห้ามซ้ำ, ชื่อ, ชื่อเล่น, เบอร์, วันเกิด, เพศ, อีเมล, รูป) และรหัสระบบที่รันอัตโนมัติ, ค้นหาด้วยชื่อ/เบอร์/HN, หน้าโปรไฟล์ที่รวมประวัติการรักษาและยาฝาก
3. **ระหว่างดำเนินการ** (ต่อจากจัดยา-เบิกยา; Front ใช้เป็นหลัก): กระดาน kanban ของวัน 5 คอลัมน์ รอดำเนินการ (ทุกวันที่ค้าง) / รอพบแพทย์ / พบแพทย์ (แยกกลุ่มตามชื่อแพทย์) / รอชำระเงิน / เสร็จสิ้น พร้อมการ์ดจำนวนคนไข้ในแต่ละสถานะ เรียงตามเลขคิว เลือกวันที่ดูย้อนหลังได้ มีปุ่มรีเฟรช และรีเฟรชเองทุก 10 นาที (เป็นหน้าเดียวที่รีเฟรชเอง); ปุ่มที่ Front ใช้: สร้าง/แก้ไขใบ OPD (ที่รอดำเนินการ), รอดำเนินการ → รอพบแพทย์, รอพบแพทย์ → พบแพทย์ (เลือกแพทย์ก่อน แล้วแสดงตัวอย่างใบ OPD พร้อมปุ่มพิมพ์), รอชำระเงิน → ชำระเงิน (เสร็จสิ้น) และย้อนสถานะ; การ์ดรอดำเนินการและรอชำระเงินไม่แสดงวันที่ค้าง (การ์ดรอดำเนินการแสดงวันที่จัดยาและป้าย "ยังไม่มีใบ OPD"); แพทย์/เซลล์แยกบรรทัด; **แจ้งเตือน**: เมื่อมีคนไข้เปลี่ยนจากพบแพทย์เป็นรอชำระเงิน เมนู "ระหว่างดำเนินการ" ขึ้นตัวเลขสีแดงและมีข้อความแจ้ง (ตรวจตอนเข้าสู่ระบบและทุกครั้งที่เปลี่ยนหน้า ไม่มีตัวตั้งเวลา) เปิดกระดานแล้วตัวเลขหาย; กดการ์ดเพื่อดูรายละเอียด
4. **จัดยา-เบิกยา**: เบิกยาจากสต๊อกให้คนไข้ (เลือกเซลล์, ตัดสต๊อกทันที, เก็บราคาทุน — ไม่มีราคาขาย เพราะลูกค้าจ่ายค่ายาให้เซลล์โดยตรง) เลือก Stock (A/B) ต่อรายการยา; ชื่อคนไข้ถ้าไม่เลือกจากรายชื่อจะบันทึกตามที่พิมพ์ (รออัพเดท); เมื่อบันทึกการเบิก ระบบสร้างบันทึกการรักษา (สถานะ **จัดยาแล้ว**) ให้ทันที; รายการที่บันทึกพร้อมกันแสดงเป็นกลุ่มเดียว (HN, ชื่อคนไข้, เซลล์, สถานะ รวมแถว แยกแถวเฉพาะยา/จำนวน/ราคา) ค้นหาด้วยชื่อ/เบอร์/HN กรองตามชื่อเซลล์ กรองตามสถานะการรักษา (เริ่มต้น = จัดยาแล้ว; เลือกเสร็จสิ้น/ทั้งหมดได้) แนบรูปยาที่เบิกได้สูงสุด 8 รูปต่อการเบิก (ตอนสร้างรายการ หรือภายหลังจากเมนู "จัดการ" > รูปยาที่เบิก — เพิ่ม/ลบได้ทั้ง admin และ staff; ย่อรูปก่อนอัปโหลด เก็บใน Drive โฟลเดอร์ปี/เดือน/วันเดียวกับรูป OPD) และมีเมนู "จัดการ" (ใส่ข้อมูลคนไข้, เปลี่ยนสถานะ, สร้าง/แก้ไข/พิมพ์ใบ OPD, รูปยาที่เบิก, ลบรายการยา — admin)
5. **บันทึกการรักษา**:
   - เลือกคนไข้ และเซลล์ เปิดบันทึกที่ "จัดยาแล้ว" มาเพิ่มหัตถการ/รายการอื่นๆ (หรือเพิ่มบันทึกใหม่เองก็ได้) สถานะการรักษา: จัดยาแล้ว → รอดำเนินการ → รอพบแพทย์ → พบแพทย์ → รอชำระเงิน → เสร็จสิ้น (หน้านี้แสดงตั้งแต่รอดำเนินการเป็นต้นไป — staff เริ่มที่ "พบแพทย์", admin เริ่มที่ "ทั้งหมด"; กดแถวเพื่อดูประวัติคนไข้ (มีปุ่ม "เพิ่มบันทึกการรักษา" เมื่ออยู่ขั้นพบแพทย์); เมนู "จัดการ" เปลี่ยนตามสถานะ: รอดำเนินการ/รอพบแพทย์ = สร้าง/แก้ไขใบ OPD, พิมพ์ใบ OPD, เปลี่ยนสถานะ, ดูประวัติ · พบแพทย์ = ดำเนินการ, ดูใบ OPD, ย้อนไปรอพบแพทย์ · รอชำระเงิน = แก้ไข, ดูใบ OPD, ดูใบเสร็จ · เสร็จสิ้น = แก้ไข (admin), ดูใบ OPD, ดูใบเสร็จ, ลบ (admin, มีให้ยืนยัน); กด "บันทึกการรักษา" แล้วสถานะเป็นรอชำระเงินทันที (ไม่เปิดใบ OPD) และแถวบันทึกใหม่ของหัตถการ/โปรเลือกแพทย์ที่เข้าพบให้อัตโนมัติ)
   - 1 เวชภัณฑ์ (ตัดสต๊อก) · 2 หัตถการ (เลือกแพทย์และหัตถการต่อบรรทัด — คนไข้ 1 คนทำกับแพทย์หลายคนได้, ยอดรวม = จำนวนเงินหัตถการ) · 3 ยา: รายการยาจากใบเบิก (ดึงอัตโนมัติ, ระบุจำนวนที่ใช้/ฝาก และวันหมดอายุ, ไม่คิดเงินในยอดรับชำระ) และรายการยาเบิกเพิ่ม (ตัดสต๊อก, ไม่คิดเงิน — ลูกค้าจ่ายค่ายาให้เซลล์โดยตรง; ต้นทุนไปอยู่ในรายงานรายเซลล์พร้อมหมายเหตุ เบิกเพิ่ม); ใช้ยาฝาก, ถือยาเข้า, Messenger · 4 รายการอื่นๆ (โปรหน้าคลีนิค เลือกแพทย์ต่อบรรทัด, Canula, อื่นๆ)
   - **คำนวณส่วนแบ่งอัตโนมัติ** ให้เซลล์ (%คอมมิชชัน), แพทย์แต่ละคน (% ของหัตถการที่ทำ + %ส่วนแบ่งของแต่ละโปร + เติมยอดขั้นต่ำรายวันแยกรายแพทย์) และคลินิก (ส่วนที่เหลือทั้งหมด รวมรายการอื่นๆ — ยาเบิกเพิ่มไม่คิดเงิน และไม่มีส่วนแบ่ง supplier) รายละเอียดยอดรับชำระไม่แสดงแถวที่เป็น 0
   - **ชำระเงิน** เป็นขั้นตอนสุดท้าย (ปุ่ม "บันทึกและชำระเงิน" หรือปุ่มชำระเงินในรายการ): สรุปยอด, วิธีชำระเงิน (เงินสด / บัตรเครดิต / โอนเงิน / ชำระผ่านเซลล์ (เลือกเซลล์) / อื่นๆ (ระบุ)), สถานะ และพิมพ์ใบเสร็จ
   - แนบรูป OPD ซึ่งเก็บใน Drive แยกโฟลเดอร์ ปี/เดือน/วัน
   - มีมุมมองรายการและมุมมองปฏิทินรายเดือน (สีตามสถานะการรักษา) พร้อมสรุปยอดรายวัน; ตารางรายการแสดง HN และสถานะการรักษา (ตัวกรองเริ่มต้น = จัดยาแล้ว) ค้นหาด้วยชื่อ/เบอร์/HN คลิกแถวเพื่อดูรายละเอียดที่แผงด้านขวา และมีเมนู "จัดการ" (ชำระเงิน, พิมพ์ใบเสร็จ, แก้ไข, ลบ)
   - **พิมพ์ใบเสร็จ** รันเลขที่อัตโนมัติ แล้วแสดงตัวอย่างใบเสร็จในหน้าต่างพรีวิว (ขนาด A4 ทั้งพรีวิว PDF และพิมพ์; รายการย่อยไม่ใส่เลขลำดับ) พร้อมปุ่ม พิมพ์ / บันทึกเป็น PDF / ปิด (ไม่แสดงกลุ่มค่ายาเมื่อไม่มียอด); หน้า `?page=receipt&ticket=...` ยังใช้เปิดแบบหน้าเดี่ยวได้ (ticket ใช้ได้ครั้งเดียวภายใน 5 นาที)
6. **รายการยาฝาก**: ยาฝากทุกคนไข้แยกเป็นล็อต (จำนวนคงเหลือ, วันหมดอายุ, บันทึกการรักษาที่มา) กรองใกล้หมดอายุ/หมดอายุแล้ว แก้วันหมดอายุได้ และ admin แก้จำนวนได้ การใช้ยาฝากตัดล็อตที่หมดอายุก่อน (ไม่ตัดล็อตที่หมดอายุแล้ว) คลิกรายการเพื่อดูสรุปและความเคลื่อนไหว (ฝาก / ใช้ / ปรับยอด วันที่ และยอดเปลี่ยนแปลง) ที่แผงด้านขวา
7. **รายงาน** (admin): เลือกช่วงวันที่และชื่อเซลล์ ดาวน์โหลด PDF ได้
   - รายงานรายวัน: วันที่, ชื่อคนไข้, ชื่อเซลล์, รายละเอียดตามใบเสร็จ, จำนวนเงิน
   - รายงานรายเซลล์: รายได้ที่คลินิกเก็บจากเซลล์ ณ ราคาทุน (ไม่มีราคาขาย) แสดงแบบ pivot — วันที่ > ชื่อเซลล์ > ชื่อคนไข้ > รายการยา (จำนวน, ราคาทุน/หน่วย, จำนวนเงิน, หมายเหตุรายการเบิกเพิ่ม) พร้อมยอดรวมต่อเซลล์/วัน และสรุปยอดแต่ละเซลล์; คลิกแถวเพื่อดูตัวอย่างและดาวน์โหลด PDF ของเซลล์/วันนั้น
8. **จัดการสินค้า/บริการ**: รายการเวชภัณฑ์ และรายการยา (สต๊อก, อัพเดตสต๊อก, ประวัติการเคลื่อนไหว, นำเข้า CSV) และรายการหัตถการ (ชื่อ, หมวดหมู่, ราคา, เปิด/ปิดใช้งาน — admin แก้ไข)
9. **ค่าใช้จ่าย & จัดซื้อ** (admin): บันทึกค่าใช้จ่ายแยกหมวด และใบสั่งซื้อ (PO) ที่มีหลายรายการต่อ supplier — คลิกแถวใน "จัดซื้อ" เพื่อดูรายละเอียด (สรุป + รายการสินค้า) ที่แผงด้านขวา แล้วกดแก้ไขต่อได้
10. **จัดการโปรโมชันหน้าคลินิก**: ชื่อโปร, ราคา, %ส่วนแบ่งแพทย์ (ส่วนคลินิกคำนวณเป็น 100 − %แพทย์) และเปิด/ปิดใช้งาน
11. **ตั้งค่าคลินิก** (admin): แพทย์/เซลล์ (%คอมมิชชัน, ยอดขั้นต่ำ), หมวดหมู่ (สินค้า/หัตถการ/ค่าใช้จ่าย), ข้อมูลบริษัท (ชื่อ, ที่อยู่, เบอร์, เลขผู้เสียภาษี, โลโก้, รูปหน้า login) และพนักงาน (สิทธิ์, LINE ID)

### LINE Messaging API
- ปุ่ม **ส่งข้อมูลไป LINE** ส่งสรุปยอดรายวันให้ admin ทุกคนที่กรอก LINE ID ไว้
- ตั้ง trigger ส่งสรุปยอดอัตโนมัติทุกวันตามเวลาที่กำหนดได้
- Chatbot ผ่าน webhook (`doPost`) รองรับคำสั่งเหล่านี้ โดยตรวจสิทธิ์จาก LINE ID ของพนักงานที่ Active
  - `Line ID ของฉัน` ตอบกลับ LINE user id ของผู้ส่ง
  - `สรุปยอดวันนี้`
  - `สรุปยอดวันอื่น [yyyy-MM]` แสดงปฏิทินให้กดเลือกวัน
  - `สรุปยอดวันที่ yyyy-MM-dd`

### อื่นๆ
- อัปโหลดไฟล์ใหญ่แบบ resumable chunk ผ่าน server โดยไม่ส่ง OAuth token ไปที่ client
- Cache master data และรายการ autocomplete ของคนไข้/สต๊อกเพื่อลดการอ่าน Sheet
- `seedDemoData` สำหรับใส่ข้อมูลตัวอย่างตาม flow ปัจจุบัน: ประวัติก่อนวันนี้จบครบ (ชำระแล้ว หรือยกเลิก) ส่วนของวันนี้กระจายทุกขั้น — จัดยาแล้ว 2 (จัดล่วงหน้าเมื่อวาน), รอพบแพทย์ 2, พบแพทย์ 2 (คนละแพทย์), รอชำระเงิน 2, เสร็จสิ้น 2 (รวมตัวอย่างครบวงจร HN1011) พร้อมเลขคิวของวันและแพทย์ที่เข้าพบ; ก่อนขั้นพบแพทย์ยังไม่มีบันทึกการรักษา
- `seedDemoData` (ปุ่ม "โหลดข้อมูลตัวอย่าง" ใน ตั้งค่า) ใส่ข้อมูลตามฟีเจอร์ ARICH ด้วย: ยาใน Stock A/B (มี Dysport ชื่อเดียวกันในทั้งสอง stock), Sale group 2 กลุ่ม + เซลล์ 3 คน (1 คนไม่มีกลุ่ม), ตารางราคาเฉพาะกลุ่ม/เซลล์ (PriceOverrides), ยาเบิกที่บันทึกราคาขายของเซลล์ไว้, ซื้อยาเพิ่มที่คิดเงินพร้อมที่มาของราคา (agent/standard/manual) และยาอื่นๆ, พัสดุที่ตัดสต๊อก, Canula มีหมายเหตุ, ใบสั่งซื้อทั้งประเภทซื้อยาจากเซลล์และซื้ออื่นๆ  (ปุ่มนี้ล้างข้อมูลธุรกิจเดิมก่อน แต่เก็บบัญชีผู้ใช้และข้อมูลบริษัทไว้)
